# Read-out — Korean (`ko`)

Read `references/readout.md` first. This file lists what Korean adds.

## Sounds the spelling shows, and the ones it hides

Korean speech changes sounds by the standard pronunciation rules (표준 발음법, 국립국어원).

| Rule (표준 발음법) | Example | In `say` |
|---|---|---|
| 연음 (제13–15항) | 옷이 [오시], 닭을 [달글] | keep the normal spelling |
| 비음화 (제18–19항) | 국물 [궁물], 담력 [담녁] | keep the normal spelling |
| 유음화 (제20항) | 난로 [날로], 칼날 [칼랄] | keep the normal spelling |
| 구개음화 (제17항) | 굳이 [구지] | keep the normal spelling |
| 거센소리되기, ㅎ 탈락 (제12항) | 놓고 [노코], 놓아 [노아] | keep the normal spelling |
| 된소리되기 (제23–28항), hidden cases | 할 것 [할껏], 발전 [발쩐], 갈등 [갈뜽], 소수점 [소수쩜] | write the sound when the line leans on the word |
| ㄴ 첨가 (제29항) | 솜이불 [솜니불], 한여름 [한녀름], 꽃잎 [꼰닙] | write the sound |
| 사이시옷 (제30항) | 냇가 [내까], 깻잎 [깬닙] | keep the spelling; it already marks the sound |

The first five show in the spelling, and the voice usually gets them right; rewriting them into
sound spelling (구궁물) makes the voice stumble. The hidden ones — 된소리 the spelling does not
mark, ㄴ 첨가, the 의 in 우리의 said as [에] — are where a line sounds read rather than spoken.

## Numbers

| Written | Say | Why |
|---|---|---|
| `4.4` | 사쩜사 | the decimal point is said [쩜] (소수점 [소수쩜]), not [점] |
| `27.3%` | 이십칠쩜삼 퍼센트 | same, and the unit spoken once |
| `3개`, `20명`, `2번`, `5살`, `3시` | 세 개, 스무 명, 두 번, 다섯 살, 세 시 | counters of native origin take native numbers |
| `3분`, `7점`, `2층`, `3일`, `1,500원` | 삼 분, 칠 점, 이 층, 삼 일, 천오백 원 | Sino counters take Sino numbers |
| `6월`, `10월` | 유월, 시월 | fixed forms |
| `3-2` (score) | 삼 대 이 | |
| `3~5` | 삼에서 오 | |
| `Opus 5.5`, `GitHub`, `xhigh` | 오퍼스 오쩜오, 깃허브, 엑스하이 | English names in Hangul, as Korean speakers say them |

## Quoting a wrong reading

"유월을 육월이 아니라 유월로 읽게": the voice corrects `육월` to 유월 by itself, and `육,월` or
`육 월` only adds a break. Spelled as heard, `유궐` is said as written:
`say: "유월을... 유궐이 아니라, 유월로 읽게"`.
