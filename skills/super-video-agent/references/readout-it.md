# Read-out — Italian (`it`)

Read `references/readout.md` first. This file lists what Italian adds.

## Sounds the spelling hides

Italian spelling is close to phonetic, but it does not mark stress, and stress often falls on a
syllable before the last one.

| Case | Example | In `say` |
|---|---|---|
| Stress on a non-final syllable, unmarked | ancora (still) vs àncora (anchor), subito | if a take stresses the wrong syllable, add an accent mark or respell |
| Open vs closed e/o, unmarked | pesca (peach, closed e) vs pesca (fishing, open e) | if the take picks the wrong word, rephrase so the meaning is clear |
| English loanwords read with Italian rules | GitHub, xhigh | respell by sound when a take misreads them (see Numbers) |
| Double consonants change the vowel before them | pena / penna, casa / cassa | leave as written; the voice already lengthens the consonant |

## Numbers

| Written | Say | Why |
|---|---|---|
| `5,5` | cinque virgola cinque | a decimal comma is said "virgola" |
| `Opus 5.5` | Opus cinque punto cinque | versions keep the dot, said "punto" |
| `21` | ventuno | tens and units join without a space in speech |
| `100`, `120` | cento, centoventi | "cento" alone or before more digits, no "un" before it |
| `1000` | mille | plural is "mila" (`2000` = duemila) |
| `1 000 000 di utenti` | un milione di utenti | "milione" takes "di" before the noun |
| `2026` (year) | duemilaventisei | one whole number, not split in pairs |
| `1° maggio` | primo maggio | day 1 is ordinal; other days are cardinal: `5 maggio` = cinque maggio |
| `15:20` | quindici e venti | 24-hour form is standard in written Italian |
| `16,34 €` | sedici euro e trentaquattro centesimi | whole unit, then "e", then the cents |
| `27%` | ventisette per cento | never left as a symbol |
| `3–5` (range) | dal tre al cinque | |
| `3-2` (score) | tre a due | not "meno" |
| `1°`, `2°` | primo, secondo | ordinal word, agrees in gender with the noun |
| `GitHub`, `xhigh` | GitHub, ics-hai | English names respelled as Italian speakers say them |
| `API` | a pi i | Italian letter names |

## Quoting a wrong reading

"Si dice però, non pèro": with `però` written in both places, the voice may read it the same way
twice. Mark the wrong stress so it cannot be corrected:
`say: "Si dice però... non pèro."`
