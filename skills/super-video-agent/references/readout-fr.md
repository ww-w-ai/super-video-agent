# Read-out — French (`fr`)

Read `references/readout.md` first. This file lists what French adds.

## Sounds the spelling hides

French spelling marks vowels and accents clearly but hides consonant linking and silent letters.

| Case | Example | In `say` |
|---|---|---|
| Liaison between words | les amis, un grand homme | leave as written; the voice makes the link on its own from word order |
| Silent final consonants | petit, beaucoup, sept | leave as written; the voice already drops them where French drops them |
| Silent final consonant that returns before a vowel | petit ami, grand arbre | leave as written; this is liaison, not a spelling gap |
| English loanwords read with French rules | GitHub, xhigh, week-end | respell by sound when a take misreads them (see Numbers) |
| e muet (mute e) | je ne sais pas | leave as written; the voice drops or keeps it by its own accent |

## Numbers

| Written | Say | Why |
|---|---|---|
| `5,5` | cinq virgule cinq | a decimal comma is said "virgule" |
| `Opus 5.5` | Opus cinq point cinq | versions keep the dot, said "point" |
| `21` | vingt et un | "et un" joins tens ending in one (not for 81, 91) |
| `80` | quatre-vingts | vigesimal counting continues to 99 |
| `100`, `120` | cent, cent vingt | "cent" alone or before a noun; no "un" before it |
| `1000` | mille | never "un mille" |
| `1 000 000 d'utilisateurs` | un million d'utilisateurs | "million" takes "de" before the noun |
| `2026` (year) | deux mille vingt-six | one whole number, not split in pairs |
| `1er mai` | premier mai | day 1 is ordinal; other days are cardinal: `5 mai` = cinq mai |
| `15:20` | quinze heures vingt | 24-hour form is standard in most written French |
| `16,34 €` | seize euros et trente-quatre centimes | whole unit, then "et", then the cents |
| `27 %` | vingt-sept pour cent | never left as a symbol |
| `3–5` (range) | de trois à cinq | |
| `3-2` (score) | trois à deux | not "moins" |
| `1er`, `2e` | premier, deuxième | ordinal word; only "1er/1re" uses a different form |
| `GitHub`, `xhigh` | GitHub, ix-haille | English names respelled as French speakers say them |
| `API` | a pé i | French letter names |

## Quoting a wrong reading

"On dit février, pas fé-vri-er": with `février` written in both places, the voice may correct the
wrong form back to normal on its own. Spell the wrong form in sound so it survives:
`say: "On dit février... pas fé-vri-er."`
