# Read-out — German (`de`)

Read `references/readout.md` first. This file lists what German adds.

## Sounds the spelling shows, and the ones it hides

German spelling is close to phonetic, but compounding and English loanwords cause the most
misreads.

| Case | Example | In `say` |
|---|---|---|
| Long compounds | Geschwindigkeit, Softwareentwicklung | the voice usually splits stress correctly; if a take runs the compound together, insert a word break by rephrasing |
| English loanwords read with German rules | Update, Meeting, Team | leave as written unless a take mixes English and German pronunciation; then respell by sound |
| English tech names | GitHub, xhigh | respell by sound when a take misreads them (see Numbers) |
| Umlaut vs base vowel | schon / schön, Mutter / Mütter | never drop the umlaut mark; it changes the word |
| ß vs ss | Straße, Fluss | leave as written; both mark the same long-vowel rule the voice already knows |

## Numbers

| Written | Say | Why |
|---|---|---|
| `5,5` | fünf Komma fünf | a decimal comma is said "Komma" |
| `Opus 5.5` | Opus fünf Punkt fünf | versions keep the dot, said "Punkt", even where the audience writes decimals with a comma |
| `21` | einundzwanzig | units before tens, joined |
| `100`, `120` | hundert, hundertzwanzig | "ein" is dropped before "hundert" in most speech |
| `1000` | tausend | "ein" is usually dropped the same way |
| `1 000 000 Nutzer` | eine Million Nutzer | "Million" takes "eine" before the noun, no "de"-equivalent needed |
| `2026` (year) | zweitausendsechsundzwanzig | one whole number, not split in pairs |
| `1. Mai` | erster Mai | ordinal day, with the case ending the sentence needs |
| `15:20` | fünfzehn Uhr zwanzig, or zwanzig nach drei | 24-hour or 12-hour form, as the audience expects |
| `16,34 €` | sechzehn Euro vierunddreißig | whole unit, then the cents, no "und" between them |
| `27%` | siebenundzwanzig Prozent | never left as a symbol |
| `3–5` (range) | drei bis fünf | |
| `3:2` (score) | drei zu zwei | not "Doppelpunkt" |
| `1.`, `2.` | erste(r/s), zweite(r/s) | ordinal word, with the ending the sentence needs |
| `GitHub`, `xhigh` | GitHub, iks-heiei | English names respelled as German speakers say them |
| `API` | a pe i | German letter names |

## Quoting a wrong reading

"Man sagt Februar, nicht Feb-ru-ar": with `Februar` written in both places, the voice may read it
the same way twice. Mark the wrong form so it cannot self-correct:
`say: "Man sagt Februar... nicht Feb-ru-ar."`
